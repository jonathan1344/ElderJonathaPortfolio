### **CASO 2: Machine Learning + Previsão de Variância**
**Empresa:** Stellantis Mopar | **Impacto:** R$50k/mês economizados (pilot 25%)

**Problema:**
- Compras 100% reativas ("o que pedimos ontem")
- Picos = stockouts, vales = overstock
- Sem previsão de problemas

**Solução:**
- Modelo ML (XGBoost, Decision Tree, Random Forest) testado
- Input: Histórico 24 meses + sazonalidade + lead time
- Output: Previsão de erro de estoque
- Regra: Se >95% confiança E erro >R$5k → pré-contagem automática
- Pilot em 25% Part Numbers críticos

**Resultado:**
- ✅ **R$50k/mês reduzido** (pilot 25%)
- ✅ Escalável para **100% dos Part Numbers**
- ✅ Conformidade de targets **previsível**
- ✅ **Leadership Principles:** Data-driven, Deliver Results, Ownership

### **CASO 3: Excel → Power BI Real-Time (Favorito)**
**Empresa:** Stellantis Mopar | **Impacto:** R$100k/mês economizados PERMANENTEMENTE

**Problema:**
- Controle 100% Excel (reativo)
- Visibilidade só ao final do mês ("quando já foi feito")
- R$250k/mês em correções desnecessárias (deltas indevidos)
- Sem pontos críticos identificados a tempo
- Sem previsão

**Solução:**
- Dashboard **Power BI real-time** com 4 camadas:
  1. **Visibilidade Real-Time:** Dados atualizados conforme inseridos (integração SAP)
  2. **Alertas Automáticos:** Quando desvios aparecem
  3. **Previsão de Trend:** "Se mantiver ritmo, quando vai atingir meta?"
  4. **Pareto (20/80):** Identifica top 20% de problemas que causam 80% das perdas
- Cultura mudou: **reativo → proativo** (daily monitoring)

**Resultado:**
- ✅ **R$250k → R$150k/mês** (R$100k/mês economizados PERMANENTEMENTE)
- ✅ Visibilidade de progresso **diária** (não final do mês)
- ✅ Pontos críticos identificados **antes** de virarem problemas
- ✅ Deltas indevidos **drasticamente reduzidos**
- ✅ **Leadership Principles:** Invent & Simplify, Deliver Results, Data-driven, Ownership
